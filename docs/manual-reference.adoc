|===
|Control |What it does |Shortcut / value
|Weak Links |Colour every block, node, event and hierarchy by its post-simulation availability, dependability or reliability, against the model's G/Y and Y/R thresholds; the value is printed under each element (digits in Preferences ▸ Advanced). |Capacity |Colour each capacity node by its average utilization (Green < 70% · Yellow < 90% · Red ≥ 90%). Needs Capacity analysis and at least one node without unrestricted flow. |

|Importance |Colour each block by its importance, using the measure the Importance tab ranks by (Vesely–Fussell when it is defined, since Birnbaum saturates in a series system). Red = highest leverage (≥ ⅔ of the largest value), Yellow ≥ ⅓, Green below; the value is printed under each block. This is a RANKING, not a health reading: red means 'fix this first'. Needs Importance measures enabled for the run. |
