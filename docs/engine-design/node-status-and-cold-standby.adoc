:toc: macro

toc::[]

== Purpose

A node joins several incoming paths and says how many must be up (k of n). When a block or event changes state it updates one incoming *link*, and the node re-aggregates its links into a status: AllUp, Degraded, Down, plus Standby, Idle and PM. A node's status then drives the next node downstream, dependents, hierarchy colours, the weak-link time columns and the system's Green/Yellow/Red.

A *cold-standby* node (a switching group, k of n with priorities) works differently. It does not aggregate inline; it queues itself in the `ColdChangeGroup` and `CheckColds` later runs `RunColdLogic`, which decides which candidates run and which wait as Standby, starts switches that take time (auto, manual or none), and logs one status line for the group.

== Structure

[mermaid]
....
flowchart TD
    change["block / event / phase change<br/>updates one incoming link"] --> cold{"cold node and<br/>not higherCold?"}
    cold -->|no| agg["determine_node_status:<br/>k-of-n over the links, log line,<br/>change_node_state, cascade downstream"]
    cold -->|yes| queue["ColdChangeGroup.add(node)"]
    queue --> check["CheckColds (flush)"]
    check --> survey["run_cold_logic: bucket the links<br/>ready / switching / auto / manual / none"]
    survey --> enough{"ready paths >= kMax?"}
    enough -->|yes| demote["keep the first k, demote the rest<br/>(Too_many_on), promote a Standby one<br/>(Prior=Standby)"]
    enough -->|no| sw["start switches (PrepForSwitch, PerformSwitch)<br/>or log Switch_Failed for a 'none' link"]
    demote --> line["one node line: N/M_up..._s..._dsw..."]
    sw --> line
....

`kMax` is k*, but a phased node with k* below k uses k ("cmc 12/21/06"). A candidate may be a block, a node (a `higherCold` freeze and a dependency back-flow), or an event (a no-op arm: `SetStuckOn` has no reader). The candidate order is the sorted link order, which is why the sort's tie behaviour is visible in the log (`ColdPriorityTieProbe`).

== State it owns

Per node: `cold_links` (the sorted order), `higher_cold`, the `path_*_value` counters. Per link: `switch_status` (`ready`, `auto`, `manual`, `none`, `autoInProgress`, `manualInProgress`, `Interrupted`), `switch_time`, and the process handle of a switch in flight.

== Port-only devices and deliberate deviations

* `ColdChangeGroup` is an insertion-ordered dict, because source's is a FIFO queue and a `set` drained in hash order once put lines in the wrong order.
* A phase change or an event that reaches a cold node must go through the same queue (they do, since 2026-09-30); aggregating inline printed a line real never prints.
* Switch interrupts are queued, with a re-entrancy guard, because source's `Interrupt` is not synchronous.
